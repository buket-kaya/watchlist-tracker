# Watchlist Tracker

A desktop application for managing personal movie and TV series watchlists, developed using Python.

## Features

- Add movies and TV series to your watchlist
- View, update, and delete existing entries
- Track watched and planned content
- Rate watched content from 1 to 10
- Filter entries by watch status
- Visualize genre distribution with charts
- Store data locally using SQLite

## Technologies Used

- Python
- Tkinter (GUI)
- SQLite (Database)
- Matplotlib (Data Visualization)

## How to Run

1. Download or clone the repository.
2. Make sure Python 3 and Tkinter are installed.
3. Install the required library:

   pip install matplotlib

4. Run the application:

   python3 main.py

## Project Structure

- `main.py` - Main application and navigation
- `windows.py` - GUI windows and user interactions
- `database.py` - Database operations and data validation

## About

This project demonstrates GUI development, object-oriented programming (OOP), CRUD operations, SQLite database integration, and data visualization using Python.
